# Day 03 - Context Engineering

## What is Context?

Context is the information, knowledge, constraints, and business understanding provided to an AI system before asking it to perform a task.

Formula:

Prompt + Context = Output

## Key Insight

AI does not fail because it is unintelligent.

AI fails because it lacks context.

## Realization

After working on ERP systems, manufacturing software, and MoM Insight 360, I realized that the same principle applies to both humans and AI:

Better Context = Better Decisions

## Context Layers

1. User Prompt
2. Current Task
3. Historical Knowledge
4. Domain Knowledge
5. Rules & Constraints
6. Business Vision

## Practical Example

Project:
MoM Insight 360

Context:
- Healthcare Domain
- 3 Branches
- Executive Dashboard
- Revenue KPIs
- Doctor Performance
- Revenue Forecast

Result:
AI can generate highly relevant solutions.
